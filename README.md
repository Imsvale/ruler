It's a ruler. Use it to measure distances.

**Modes**
* Line: Distance between two points.
* Polyline: Distance of each line segment, and their sum.
* Radius of a circle.

**Measure**
* 2D: Horizontal distance between two points (ignoring height differences).
* 3D: Includes height.
* Terrain: Distance along the terrain.

Snaps to stations, industries, towns, and points placed by the ruler itself.
